# دستیار — دستیار هوش مصنوعی شخصی 🤖

یک دستیار هوش مصنوعی **Local-First** با مکالمهٔ فارسی، حافظهٔ دائمی، کنترل صوتی و پل ارتباطی با **Minecraft** — که روی کامپیوتر شخصی خودت اجرا می‌شود.

## ✨ امکانات

| بخش | قابلیت‌ها |
|---|---|
| **چت فارسی** | لحن طبیعی تهران، سه حالت لحن (صمیمی/رسمی/شوخ‌طبع)، تنظیم اختصار، استریم زنده، تایپ‌رایتر، **پخش خودکار صدا** |
| **مدل‌های داخلی رایگان** | ۵ مدل آماده (دستیار فارسی، کدنویس، داستان‌سرا، معلم، هم‌تیمی ماینکرفت) — **بدون کلید API، بدون ثبت‌نام**؛ تشخیص خودکار مدل‌های محلی Ollama/LM Studio |
| **حافظهٔ دائمی** | «این رو یادت بمونه» / «این رو فراموش کن»، استخراج خودکار (Regex)، فیلتر دسته‌بندی، خروجی JSON، مسدودسازی رمز/توکن |
| **مکالمهٔ صوتی** | گوی نئونی با امواج واکنش‌گرا، تشخیص گفتار فارسی (`fa-IR`)، **Barge-in** (قطع کلام)، TTS با صدای فارسی مرورگر |
| **ماینکرفت** | دستورهای فارسی (دنبال‌کردن، مختصات، جمع‌آوری بلوک)، **حالت محافظت پلیسی** 🛡️، **حالت موشک** 🚀 (اسپرینت+پرش)، **اتوکلیک** ⚔️ (حملهٔ خودکار)، لاگ زنده |
| **حالت آفلاین** | بدون کلید API: ساعت، تاریخ، حافظه، راهنما و همهٔ دستورهای ماینکرفت — بدون خطا |
| **ویندوز** | اجرای یک‌کلیکی با `start-dastiar.bat`، پنجرهٔ Electron، ساخت خودکار `Dastiar Setup 1.0.0.exe` در GitHub Actions |

## 🚀 راه‌اندازی سریع

### پیش‌نیاز
- **Node.js 18+** ([nodejs.org](https://nodejs.org))

### ویندوز (یک‌کلیکی)
فایل `release/start-dastiar.bat` را اجرا کن — خودش وابستگی‌ها را نصب، دیتابیس را آماده و برنامه را در مرورگر باز می‌کند.

### دستی (هر سیستم‌عامل)
```bash
npm install        # نصب وابستگی‌ها
npm run db:sync    # آماده‌سازی دیتابیس محلی
npm run dev        # اجرای توسعه روی http://localhost:3784
# یا برای اجرای نهایی:
npm run build && npm start
```

### اتصال به ارائه‌دهندهٔ هوش مصنوعی
**نیازی به تنظیم نیست!** برنامه با «هوش مصنوعی داخلی» (رایگان، بدون کلید) روشن می‌شه و همون اول کار می‌کنه.
از صفحهٔ **تنظیمات** می‌تونی مدل رو عوض کنی یا ارائه‌دهندهٔ خودت رو وصل کنی:
- **🆓 هوش مصنوعی داخلی** → ۵ مدل رایگان، بدون کلید API
- **OpenAI / OpenRouter / Groq / xAI** → کلید API خودت را وارد کن
- **Ollama / LM Studio** → بدون کلید، روی `localhost` کار می‌کند (مدل‌ها خودکار لیست می‌شن)
- اگر اینترنت قطع بشه، دستیار در **حالت آفلاین** کار می‌کنه و هیچ خطایی نمی‌بینی.

## 🎮 دستورهای ماینکرفت (فارسی)

| دستور | کار |
|---|---|
| «بیا دنبالم» | دنبال‌کردن بازیکن با pathfinder |
| «وایسا» / «توقف فوری» | توقف کامل حرکت، ماینینگ و حالت‌ها |
| «برو به مختصات ۱۰۰ ۶۴ -۳۰» | رفتن به مختصات (ارقام فارسی/انگلیسی/منفی) |
| «چوب جمع کن» / «سنگ جمع کن» | جمع‌آوری بلوک تا شعاع ۴۸ |
| «محافظت کن» | 🛡️ حالت پلیسی: دنبال کردن + درگیری با ماب‌های خصم |
| «موشک روشن» | 🚀 اسپرینت و پرش مداوم (ونیلا، بدون تقلب) |
| «اتوکلیک روشن» | ⚔️ کلیک چپ مداوم روی نزدیک‌ترین دشمن |
| «بپر» / «به من نگاه کن» | ... |
| «تو چت بگو سلام» | پیام در چت بازی |
| «گزارش وضعیت» | مختصات، جان، سیری، بازیکنان آنلاین |

> **نکتهٔ امنیتی:** ربات با معماری **Whitelist** کار می‌کند؛ مدل زبانی هرگز کد دلخواه اجرا نمی‌کند — فقط دستورهای ازپیش‌تعریف‌شده.

## 🛡️ قوانین حافظه

1. **یادآوری صریح:** «این رو یادت بمونه: ...» → ذخیرهٔ فوری
2. **فراموشی:** «این رو فراموش کن: ...» → حذف رکوردهای منطبق
3. **استخراج خودکار:** «اسم من علیه» → ثبت با Regex بدون صدا زدن مدل
4. **امنیت:** رمز، پسورد، API Key و توکن **هرگز** ذخیره نمی‌شوند
5. **تزریق به پرامپت:** تا ۴۰ حافظهٔ آخر در هر گفتگو به مدل داده می‌شود

## 📦 ساخت EXE ویندوز

1. پروژه را به GitHub پوش کن
2. ورک‌فلوی `.github/workflows/build-windows.yml` روی `windows-latest` اجرا می‌شود
3. از بخش **Actions → Artifacts** فایل‌های زیر را دانلود کن:
   - `Dastiar Setup 1.0.0.exe` (نصبی NSIS)
   - `Dastiar Portable 1.0.0.exe` (پرتابل)

اجرای دستی: `npm run dist:win`

